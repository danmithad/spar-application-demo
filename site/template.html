Who Grades the Graders?

A pipeline labels annual-report passages as AI adoption, risk, vendor, or harm. An LLM judge assigns more labels than the human annotators did — and spot checks say many of the extra labels are valid. Is the LLM judge better? This page makes the question precise, then answers it for a bench of current models on real Observatory data.

Item 1 · The question

"Better" is undefined until you fix three things

A judge that emits more labels will usually trade precision for recall: fewer missed labels (false negatives), more spurious ones (false positives). Whether that trade is an improvement is not a fact about the judge — it depends on three commitments the evaluator has to make explicitly:

1. A ground truth that is independent of both judges — otherwise "the human missed valid labels" and "the LLM hallucinates labels" are indistinguishable claims.
2. An error-cost weighting — how much a false positive hurts relative to a false negative. Fβ makes that weighting a single explicit parameter instead of a hidden assumption.
3. A test of the difference — with a finite evaluation set, an observed gap can be an artifact of which passages happened to be sampled. A paired bootstrap answers whether the gap survives resampling.

Everything below is that recipe, executed end-to-end on the AIRO v1.0 dataset (AI Security Institute, CC BY 4.0): 24,189 AI-keyword passages from 11,112 UK annual reports, 2020–2025.

Item 2 · Ground truth

A written rubric, applied blind

Fifty passages were sampled from the AIRO golden set, stratified across the pipeline's own phase-1 strata so all four labels and the no-label case appear (all three harm passages in the corpus are included — at 3 in 24,189, harm is the class that breaks naive averaging). Each passage was then hand-labeled against the four definitions below by Claude (Fable 5), working from a written rubric fixed before any judge was run, seeing only the passage text — no company metadata, no judge outputs.

adoption

The reporting company itself uses, deploys, develops, pilots, or integrates AI in its operations, products, or services.

Not: industry commentary, uncommitted aspiration ("we may explore AI"), or a portfolio company's / customer's use.

risk

AI identified as a source of potential adverse outcome for the company — operational, model error, security, regulatory, reputational, competitive. Boilerplate risk-factor language counts.

Not: AI used as a risk-mitigation tool (that's adoption).

vendor

The company obtains AI capability from, or depends on, an external party — third-party models, cloud AI services, AI platforms, AI-critical compute framed as a dependency.

Not: generic IT outsourcing, or the company selling AI to others.

harm

A negative AI-related event that has happened or is concretely in progress — an incident, filed litigation, discovered failure, realized loss.

Not: potential-only language; that stays risk. Tense is the boundary.

The mere appearance of the word "AI" never suffices for any label; negations get none; the empty set is a valid answer (15 of 50 passages carry no label). The full rubric, with tie-breakers and boundary rules, ships with the code. Every gold decision is inspectable in Item 6, including the deliberately strict calls — e.g. a platform described only as "algorithmic" is not AI-framed in the passage, so it earns nothing.

Declared conflict: the ground truth was written by an Anthropic model and the bench ranks Anthropic models among others. In a real validation this is disqualifying — the rubric-writer and the adjudicator must be independent of every judge under test. Here it is a demo constraint, stated rather than hidden; read the Anthropic rows with that discount.

Item 3 · The metric

Fβ puts the FP/FN exchange rate on a dial

For each label class, precision P = TP/(TP+FP) and recall R = TP/(TP+FN) are computed over all 50 passages, then combined:

Fβ = (1 + β²) · P · R / (β² · P + R)

β is the exchange rate: β < 1 penalizes false positives more (a strict auditor's judge), β > 1 penalizes misses more (a screening judge feeding human review). Micro-averaging pools every (passage, label) decision, so common classes dominate; macro-averaging gives each of the four classes equal weight, so the rare harm class counts as much as adoption. For the Observatory — whose output is prevalence statistics for governments, where under-counting rare substantive disclosure is the costlier error — a screening posture (β ≥ 1) with macro visibility on rare classes is the defensible default. The dial below lets you disagree.

Item 4 · Inference

A paired bootstrap decides if the gap is real

The evaluation set is 50 passages; a different sample would give different scores. To test whether judge A actually outperforms judge B, passages are resampled with replacement B = 2,000 times — keeping each passage's gold labels and both judges' predictions together, so the comparison stays paired — and Δ = Fβ(A) − Fβ(B) is recomputed on each resample. The 95% interval of those Δs, and the one-sided p-value p = #{Δ ≤ 0}/B, are reported below. Intervals that cross zero mean the ranking at that β is not settled by these 50 passages.

Honest footnote: passages cluster within filings (two of the harm passages come from the same Gear4Music report), so the exchangeable-passage bootstrap here is slightly anti-conservative; at production scale you resample at the document level.

Item 7 · Limitations

What this demo does not license

One annotator, no agreement ceiling. Ground truth here is a single (machine) annotator applying a rubric. A real validation needs ≥2 independent expert annotators and a reported inter-annotator agreement — the ceiling any judge comparison must be read against.

Judge–adjudicator dependence. As declared in Item 2: an Anthropic-authored gold standard plausibly flatters Anthropic judges (shared training priors about label semantics), and the same critique applies to any lab's model grading its own family.

Selection via the pipeline's own strata. Sampling was stratified on AIRO's phase-1 labels to guarantee class coverage, so class balance is designed, not natural — per-class scores are meaningful, pooled prevalence is not.

Single operating points. Each judge ran one prompt at default settings. An LLM judge's precision/recall point is cheap to move (prompt strictness, self-consistency); ranking judges at arbitrary operating points conflates tuning with ability.

n = 50. Deliberately small enough to hand-adjudicate every disagreement — the bootstrap intervals below are wide, and that is the honest message of the page: at this n, most "who's better" claims don't clear zero.
